When the pipeline is red

403 pushing to ghcr.io
The job is missing permissions: packages: write.
toomanyrequests pulling a base image
Docker Hub's anonymous rate limit. Log in, even for a pull.
The cache never hits
Look for Cache restored from key: in the log. No line means no cache — usually a key with no hashFiles() in it.
A job says skipped and the check still passed
Working as designed. A required check counts a skipped job as passed.
